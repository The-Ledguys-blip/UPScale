========================================
  UPScale - Windows 11 build (START HERE)
========================================

Versie wordt automatisch uit led-pixelmap-tool_121.html gelezen.

STAP 1 - Python
  Download Python 3.11 van https://www.python.org/downloads/
  VINK "Add Python to PATH" aan, klik Install Now.
  Controle:  py --version

STAP 2 - Dependencies
  Open Command Prompt in DEZE map en run:
      py -m pip install -r requirements.txt
  (staat requirements.txt er niet? dan: py -m pip install PyInstaller PySide6)

STAP 3 - Bouwen
      py build_app_windows.py            (alleen dist\UPScale\UPScale.exe)
      py build_app_windows.py zip        (+ draagbare zip)
      py build_app_windows.py installer  (+ Inno Setup installer)

  Voor de installer: installeer Inno Setup 6
  https://jrsoftware.org/isdl.php

STAP 4 - Testen
  Start dist\UPScale\UPScale.exe
  Maak een project, sla op, exporteer een afbeelding.
  Export komt in Downloads\UPScale-export-*

STAP 5 - Delen
  Installer : installer_output\UPScale-Setup-<versie>.exe
  Draagbaar : dist\UPScale-<versie>-win64.zip

Zie WINDOWS_BUILD.md voor uitgebreide uitleg en probleemoplossing.
